Production-ready RAG system with advanced retrieval augmentation. Implements corrective loops with TF-IDF chunk retrieval, relevance checking, query rewriting & grounded answer generation powered by Gemini 2.5 Flash. Full Streamlit deployment with PDF/TXT ingestion.

**Tech:** RAG • TF-IDF • Gemini API • Streamlit • LLM  
**Stars:** ⭐ Most Advanced Project

---

### 🔁 [Consumer Complaint Classifier](https://github.com/nsr51324/Consumer-Complaint-Classifier-For-NLP)
Advanced NLP classifier using LSTM & DistilBERT for categorizing consumer complaints. Sequence modeling with pre-trained transformers for accurate text classification with production deployment.

**Tech:** LSTM • DistilBERT • NLP • Streamlit  
**Impact:** High-accuracy text classification system

---

### 🏠 [Airbnb European Cities Analytics](https://github.com/nsr51324/Airbnb-Prices-in-European-Cities)
End-to-end data analytics pipeline on 51k+ Airbnb listings across 10 European cities. Medallion Architecture (Bronze/Silver/Gold) with Star Schema warehouse on SQL Server & interactive Power BI dashboard.

**Tech:** Pandas • SQL Server • Power BI • Star Schema • ETL  
**Scale:** 51,000+ records • 10 cities • Complete BI solution

---

### 🦷 [Oral Diseases Classification](https://github.com/nsr51324/Oral-Diseases-Image-Classification)
Deep learning benchmark for intraoral disease screening across 6 conditions. ResNet50 achieves 94.77% accuracy vs DenseNet121, EfficientNet-B0 & custom CNN. Gradio deployment for clinical use.

**Tech:** ResNet50 • PyTorch • Gradio • Medical AI • Computer Vision  
**Accuracy:** 94.77% (State-of-the-art)
